## v3.0 (2026-08-03) — 两种绘制模式，质的飞跃

### 核心理念
> 「预览很好，画出来一般」的根因：画的是两条边线描出的轮廓，不是一条真实的线。
> 预览用 Paint.strokeWidth 一次性渲染，均匀自然；绘制拆成两条边线，三重误差叠加。

### 模式 A：自动加粗（默认）
- Paint.getFillPath 生成加粗轮廓 → **直接传 Path 给 dispatchGesture**
- 不拆点、不重连，系统硬件级插值，零精度损失
- 长笔画自动拆短（>300px → 2~3段），减少累积误差
- 默认 0.75x 速度，降低系统丢点偏差
- 全程 Float 亚像素，不取整
- 自适应粗细：密集区域自动降粗

### 模式 B：单线精准
- 只画骨架细化后的单条中心线
- 最快速度 1.0x，零手绘效果
- 粗细交给目标应用自己的画笔
- **精度最高，效果直接拉满**

### UI 变化
- "画法"改为"模式"
- "快速/仿手绘" → "自动加粗/单线精准"

## v2.1 (2026-08-02) — 修复：直接用中心线绘制，不做预膨胀

### 根因修复
v2.0 的错误：`getFillPath` 生成的是闭合双线轮廓，把这个轮廓当笔画路径画 → 画的是"轮廓的轮廓"，自交重叠导致细节消失。

v2.1 修复：
- **彻底放弃 getFillPath 预膨胀**
- 直接用原始中心线坐标作为 `dispatchGesture` 路径
- 粗线效果通过降低绘制速度实现（慢速 → 手势停留更久 → 自然渗透变粗）
- THIN: 1.0x 速度, MEDIUM: 0.35x, THICK: 0.15x
- P1 密集区域自适应降粗保留（密度高 → 速度加快 → 线更细）

### 单元测试：12/12 通过

## v2.0 (2026-08-02) — 预览级精准加粗

### 核心原则
**预览用什么加粗规则，绘制就用完全相同的规则**

### P0: Paint.getFillPath 与预览 100% 对齐
- 废弃手写多层叠加/法线偏移
- 用和预览完全相同的 Paint 参数（strokeWidth/Cap.ROUND/Join.ROUND/ROUND corner）调用 `getFillPath()`
- 系统原生计算加粗轮廓，几何零误差

### P1: 密集区域自适应降粗
- 每笔画计算周围线条密度（8% rectSize 搜索半径）
- 低密度（≤1条邻居）：100% 粗度
- 中密度（2-3条邻居）：70%
- 高密度（≥4条邻居）：50%
- 短笔画（<80px）额外降粗 30%

### P2: 高密度采样
- 直线：2px 步长
- 转角 >15°：1px 步长加密插值
- 消除折线感

### P3: 手绘效果全关
- jitter/curve/bend/hook 全部默认 0
- 纯忠实临摹模式

### P4: 去除伪闭合
- 检测首尾距离 <15px 的路径
- 找最窄处（<首尾距离30%），打断恢复两条独立线

### 单元测试
- 17 个纯 JVM 测试全部通过
- 覆盖：自适应粗细、采样间距、伪闭合打断、最窄点查找

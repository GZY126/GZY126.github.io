## 一、项目概述

SimpleDrawBot 是一个 Android 平板应用，通过悬浮窗 + 无障碍服务实现在任意应用（便签、画板、相册）上自动绘制简笔画。

核心流程：
```
用户输入描述文字 → AI生成极简简笔画图片 → OpenCV提取轮廓 → AccessibilityService注入手势 → 绘制完成
```

同时支持搜图模式：在悬浮窗内置 WebView 中通过百度搜图下载图片，提取轮廓后绘制。

## 四、v1.8 绘制渲染优化详解

### 4.1 描粗算法重写：Paint.getFillPath 替代手写法线偏移

**旧问题**：手写法线偏移在曲线转角处方向不准，导致转角内侧线条重叠、外侧裂开、粗细不均。

**新方案**：
```kotlin
val paint = Paint().apply {
    style = Paint.Style.STROKE
    strokeWidth = thicknessPx  // 细线=0, 中粗=4px, 粗线=7px
    strokeCap = Paint.Cap.ROUND
    strokeJoin = Paint.Join.ROUND
    isAntiAlias = true
}
val fillPath = Path()
paint.getFillPath(originalCenterPath, fillPath)
// 用 PathMeasure 从 fillPath 采样坐标点
```

**效果**：转角/端点由系统优化处理，不会出现重叠、裂开、粗细不均。

### 4.2 关闭所有手绘效果

| 参数 | 旧值 | 新值 |
|------|------|------|
| JITTER_FACTOR | 0.0025 | **0** |
| CURVE_FACTOR | 0.004 | **0** |
| 弯曲触发概率 | 15% | **关闭** |
| 回钩触发概率 | 8% | **关闭** |

绘制结果与预览图 1:1 还原。

### 4.3 坐标精度提升

- 坐标映射全部使用 Float 计算
- 关闭缓动插值，直接画原始路径
- 描粗膨胀轮廓用 PathMeasure 每 8px 采样

## 五、v1.7 轮廓提取优化详解

### 5.1 三路独立参数映射

一个 detailLevel 滑块内部拆成三个独立维度：

| 维度 | 控制内容 | 范围 | 联动规则 |
|------|----------|------|----------|
| 开运算 | 去噪/去小斑点 | 0~4 | detail<20→4, <40→3, <60→2, <80→1, ≥80→关 |
| 闭运算 | 连线强度 | 0~3 | detail<20→3, <40→2, <60→1, ≥60→关闭 |
| 面积截断 | 细节保留比例 | 10%~100% | 线性映射 detailLevel/100 |

### 5.2 超精细模式（detailLevel≥90）

| 参数 | detail<70 | detail≥90 |
|------|-----------|-----------|
| dpEpsilon | ×1.0 | ×0.3 |
| minArea | 线性 50→5 | 1 |
| 开运算/闭运算 | 按档位 | 全部关闭 |

### 5.3 兜底重试机制

第一次提取失败（笔画数<10或最大轮廓<5%面积）→ 自动关闭开运算+低adaptiveC重试。

### 5.4 小闭合轮廓强制保留

包围盒 < 0.008 的闭合圆（眼睛/纽扣）不参与截断，强制保留。

### 5.5 伪闭合过滤

内轮廓(level≥1)且面积<20px 的直接丢弃。

## 六、v1.6 搜图选择器详解

### 6.1 候选图选择器

JS 打分遍历所有 img/canvas → 取分数最高 6 张 → 并行下载缩略图 → GridLayout 2列选择面板 → 用户选择后下载原图提取。

### 6.2 预览裁剪 + 删笔撤回

- 预览区拖动框选保留区域
- 单击删除最近笔画
- 撤回按钮恢复删除的笔画
- 重置按钮恢复完整预览
